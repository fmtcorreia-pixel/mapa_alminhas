Alojar App no Netlify (Passo a Passo)

Colocar online grátis e instalar no telemóvel

Opção A: Ligar o teu GitHub ao Netlify (Atualização Automática)
  1. Guarda o código desta aplicação num ficheiro chamado exatamente index.html e coloca-o no teu repositório do GitHub.
  2. Acede a app.netlify.com no computador e inicia sessão (podes entrar com a tua conta GitHub).
  3. No painel do Netlify, clica no botão "Add new site" → "Import an existing project".
  4. Escolhe "GitHub", autoriza o acesso e seleciona o teu repositório onde está o index.html.
  5. Deixa os campos Build command e Publish directory em branco e clica no botão "Deploy site".
  6. Em 15 segundos o Netlify cria o teu link (ex: rotadasalminhas.netlify.app). Sempre que atualizares o index.html no GitHub, o site atualiza sozinho!
Opção B: Arrastar Pasta Diretamente (Netlify Drop)
  1. No teu computador, cria uma pasta nova (ex: alminhas) e coloca lá dentro o ficheiro index.html.
  2. Abre app.netlify.com/drop no navegador.
  3. Arrasta a pasta inteira para dentro do círculo tracejado na página do Netlify.
  4. O link fica online de imediato!
Como instalar no ecrã principal do Telemóvel:

Abre o link do Netlify no telemóvel → No Android (Chrome) toca nos 3 pontos no topo direito e escolhe "Instalar aplicação / Adicionar ao ecrã principal". No iPhone (Safari) toca em Partilhar (em baixo) e escolhe "Adicionar ao Ecrã Principal".
